## Codebase Patterns

### detectTracker/deducePrStrategy now live in lib/install-runner.mjs
- **Where**: `lib/install-runner.mjs:1–18`
- **Pattern**: These helper functions were moved from hooks/install.mjs when the hook was deleted. Tests import them from `../lib/install-runner.mjs`.

### Test script is an explicit file list (not a glob)
- **Where**: `apps/claude-code/unic-archon-dlc/package.json:13`
- **Pattern**: The `test` script lists every test file explicitly. New test files must be appended to this list.
- **Example**: `"test": "node --test test/foo.test.mjs test/bar.test.mjs"`

### ExecFn injection pattern for testability
- **Where**: `lib/archon-check.mjs`
- **Pattern**: Pass `execFileSync` as an optional parameter with `typeof execFileSync` cast to a simpler `ExecFn` typedef to avoid TypeScript overload complexity. Tests inject a stub returning a string; production code falls back to the real import.
- **Example**: `export function checkArchon(execFn = (execFileSync)) { ... }`

### Biome import sort order: node: builtins first, then relative
- **Where**: `test/archon-check.test.mjs`
- **Pattern**: Biome enforces alphabetical sort within each import group. Named exports must also be sorted alphabetically (e.g. `{ checkArchon, INCOMPATIBLE_ARCHON_VERSIONS }`).
