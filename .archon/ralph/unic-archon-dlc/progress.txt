## Codebase Patterns

### Plugin package.json shape
- **Where**: `apps/claude-code/auto-format/package.json`
- **Pattern**: type module, private true, engines node>=22 pnpm>=10, scripts: test/typecheck/bump/sync-version/tag/verify:changelog/ralph, devDeps all use catalog: pinning except @unic/* which use workspace:*
- **Example**: `"@ralph-orchestrator/ralph-cli": "catalog:", "@unic/release-tools": "workspace:*"`

### plugin.json shape
- **Where**: `apps/claude-code/auto-format/.claude-plugin/plugin.json`
- **Pattern**: name, version, description, author {name, url}, homepage, license LGPL-3.0-or-later, keywords

### marketplace.json shape
- **Where**: `apps/claude-code/auto-format/.claude-plugin/marketplace.json`
- **Pattern**: metadata (description, homepage), name, owner {name}, plugins array with: author, category, description, displayName, homepage, keywords, license, name, source "./", tags, version

### CHANGELOG format required by verify:changelog
- **Where**: `packages/release-tools/scripts/verify-changelog.mjs`
- **Pattern**: Must have `## [Unreleased]` with subsections `### Breaking`, `### Added`, `### Fixed`. Versioned releases must use em-dash: `## [0.1.0] — YYYY-MM-DD`

### tsconfig.json
- **Where**: `apps/claude-code/auto-format/tsconfig.json`
- **Pattern**: extends `@unic/tsconfig/tsconfig.base.json`, include `scripts/**/*.mjs` and `tests/**/*.mjs`. Will fail TS18003 if no files exist — acceptable until first source file is created.

### pnpm catalog entries
- **Where**: `pnpm-workspace.yaml`
- **Pattern**: `@ralph-orchestrator/ralph-cli`, `@types/node`, `typescript`, `prettier`, `@biomejs/biome` are in catalog. Use `catalog:` for devDeps.
