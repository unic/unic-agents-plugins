# /unic-dlc-qa

Runs the `qa` box: end-to-end tests → coverage gate → UAT sign-off → PR-base verification → merge.
It is also an **issue-producing on-ramp** — when UAT surfaces a defect, the workflow files it directly
as an **agent-ready tracker issue** (feeding `/tickets`) instead of only halting. Ported to the
key-discriminated Archon node schema ([ADR-0011](../../docs/adr/0011-archon-schema-target.md)); design in
[ADR-0025](../../docs/adr/0025-qa-pipeline-onramp.md).

## Usage

```
/unic-dlc-qa <slug>
```

`<slug>` is the session identifier from `/unic-archon-dlc:specs` / `tickets` / `build`. The only
prerequisite baton is `<artifacts_dir>/<slug>/PRD.md` (the acceptance criteria the UAT checklist reads
from), which `/build` implemented against.

## What this workflow does

1. **bootstrap** — parse the slug from `$ARGUMENTS`, read `.archon/unic-dlc.config.yaml`
   (`artifacts_dir`, `gates.qa`, `qa.e2e_command ?? build.e2e_command`,
   `qa.coverage_threshold ?? build.coverage_threshold`, `tracker.type`, `project.branching`), confirm
   `PRD.md` exists, and **derive the target repository** from the worktree's `origin` remote
   (`project.repo_ref` is an optional override, absent by default). Missing preconditions cancel
   cleanly with a "run /build first" message; an ambiguous repository cancels with its own message.

2. **e2e** — run the resolved e2e command; **skips with a warning** when none is configured. Reports a
   verdict (does not hard-fail).

3. **coverage-gate** — run coverage and compare to the resolved threshold; **skips** when no threshold
   is configured. Reports a verdict.

4. **uat-prep** — build a numbered UAT checklist (`AC-1`, `AC-2`, …) from the PRD acceptance criteria +
   `/build`'s goals-check matrix in `report.md`, and print it.

5. **uat-gate** — **HITL by default** (`gates.qa`); skipped in AFK. The human reviews the checklist and
   the e2e/coverage results. On **reject**, each failing item is **filed as an agent-ready tracker
   issue** (composing the configured tracker + `classification.labels`, the inlined finding-capture brief shape, blocked-by
   honesty, and the `> *This was generated by AI during QA.*` disclaimer), then the gate re-pauses so a
   second reject halts the run.

6. **verify-pr-base** — confirm the open PR targets the expected base (`develop` on Gitflow, else
   `main`), composing the registered tracker system-skill and naming the derived repository
   explicitly. Reports `base_ok`.

7. **merge-gate → merge** — **HITL by default** (`gates.qa`); skipped in AFK. On approval (or in AFK)
   the PR is merged via the configured tracker and the feature branch is cleaned up on Gitflow. The
   merge **fail-closes**: it never runs on a failed e2e/coverage or a wrong base, in either mode.

## Gates & AFK

`gates.qa` (default `hitl`) governs **both** the UAT gate and the merge gate. Set it to `afk` to run the
whole pipeline unattended — the gates are skipped and a clean build auto-merges. A red e2e/coverage or a
mismatched PR base blocks the merge even in AFK (fail-closed `when`).

## Prerequisites

- `/unic-archon-dlc:build <slug>` has run and its PR has been reviewed.
- `<artifacts_dir>/<slug>/PRD.md` exists.
- `.archon/unic-dlc.config.yaml` is present (from `/unic-archon-dlc:setup`).
- The current branch has an open PR targeting the base branch (for verify-pr-base + merge).
- The checkout has an `origin` remote, or `project.repo_ref` is set.
- Archon ≥ 0.5.0.

## Configuration reference

Read from `.archon/unic-dlc.config.yaml`:

| Field                   | Type         | Default     | Description                                                                   |
| ----------------------- | ------------ | ----------- | ----------------------------------------------------------------------------- |
| `gates.qa`              | `hitl`/`afk` | `hitl`      | HITL pauses at UAT + merge; AFK skips both and auto-merges a clean run        |
| `qa.e2e_command`        | string/null  | `null`      | e2e command; falls back to `build.e2e_command`; null → e2e skipped            |
| `qa.coverage_threshold` | number/null  | `null`      | Minimum coverage %; falls back to `build.coverage_threshold`; null → skipped  |
| `artifacts_dir`         | string       | `workflows` | Session artefact home (`<artifacts_dir>/<slug>/`)                             |
| `tracker.*`             | object       | —           | Composed for issue filing, PR-base check, and merge (MCP-first, CLI-fallback) |
| `classification.labels` | object       | —           | Single source of truth for the labels QA findings carry                       |
| `project.branching`     | string       | `gitflow`   | `gitflow` → base `develop` + branch cleanup; else base `main`                 |
| `project.pr_strategy`   | string       | `squash`    | Merge style: `squash`, `merge` or `rebase`                                    |
| `project.repo_ref`      | string       | _absent_    | Optional override; by default the repository comes from `origin`              |

## Runs

```
archon workflow run unic-dlc-qa --input <slug>
```
