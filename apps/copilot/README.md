# GitHub Copilot Plugins

This directory is reserved for future Plugins targeting the GitHub Copilot agent runtime. It is intentionally empty.

The monorepo is structured to host Plugins for multiple agent ecosystems under `apps/<agent>/<plugin>/` — see the root [`AGENTS.md`](../../AGENTS.md) and [`CONTEXT.md`](../../CONTEXT.md) for the cross-cutting Plugin / Workspace Package / Release / Consumer vocabulary.
