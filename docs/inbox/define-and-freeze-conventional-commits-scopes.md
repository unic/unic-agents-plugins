Define and freeze conventional commits scopes

1. chore:
   1. per technology (like prettier, biome, js, ts, etc)
   2. per dev-tech (like VSCode, WebStorm, etc)
2. feat or fix: per app or per package (like unic-confluence, pr-review, biome-config)
3. docs for PRDs, ARDs or plans: per app or package or whole repo (like pr-review, release-tools, unic-agents-plugins)
