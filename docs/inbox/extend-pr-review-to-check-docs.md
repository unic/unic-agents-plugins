extend pr-review to check docs:

The target is to gather more context about the why of the PR

- check the pr description
- check the related Work Item (if available) in the PR
  - If there is a related work item, check the description from the ticket
  - The description from the ticket may contain a link or more to confluence pages
    - If there's a link or more to confluence pages, check them
