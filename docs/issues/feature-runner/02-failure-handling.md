## What to build

Extend the skill to handle `/tdd` sub-agent failures. When `/tdd` fails on an issue, append a failure note to that issue file under a `## Comments` heading, leave the issue at `Status: ready-for-agent`, stop the runner, and leave the worktree in place for inspection. Subsequent issues in the feature must not run — they could inherit a broken foundation.

- [ ] The runner stops after the first failure; no subsequent issues in the feature are executed
- [ ] The worktree is left in place (not removed) on failure, for inspection
- [ ] The runner surfaces a clear failure message to the user naming which issue failed
